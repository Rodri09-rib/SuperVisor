# Sobre o projeto

O SuperVisor é uma plataforma web para a gestão, alocação e publicação de escalas/folgas/usuários de trabalho operacionais,
desenhada para automatizar o planejamento de equipes e garantir o cumprimento de regras operacionais.

# Tecnologias utilizadas
Backend: Desenvolvido em Java 21 e Spring Boot 3,
utilizando Spring Security, Spring Data JPA, validação de esquemas SQL via migrações
e base de dados PostgreSQL, apoiado por uma suíte de testes unitários e de integração 
(mais de 350 testes automatizados).

Frontend: Interface reativa construída com Thymeleaf,
Bootstrap 5 e Vanilla JS, integrada via REST API com manipulação de tokens JWT no localStorage 
e componentes modais interativos para gestão ao vivo.
